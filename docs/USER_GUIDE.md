# 使用说明

## 读到哪里，就问到哪里

选中 DeepSeek 回答里至少两个字符，点击附近的“追问”。小窗会保留所选文字，输入具体问题即可发送；也可以点“解释一下”或“举个例子”。小窗回复不覆盖原回答。

回答期间仍可输入并发送后续问题。同一个选区的后续问题会排队，等前一问结束后，带上它的回复再发送。选择另一个词会建立另一条小窗讨论；同一个阅读页仍共用回答标签页，后台按队列处理。

## 不选文字也能问

左键点击桌宠打开小窗，输入问题会结合当前页面最后可识别的回答。如果窗口已打开，左键可收起。收起会保留当前页面内的讨论和草稿。

## 上下文范围

输入区下方可选择范围，选择会记住：

| 选项 | 本次额外附带的材料 |
| --- | --- |
| 仅当前回答（默认） | 当前或选中的回答，不扫描整段历史列表 |
| 最近 2 轮 | 可识别对话中的最近 2 轮，并附带当前回答 |
| 最近 4 轮 | 可识别对话中的最近 4 轮，并附带当前回答 |
| 全部对话 | 当前页面已加载且可识别的文字历史，仍受长度预算约束 |

无论选择哪项，选中文字、所在段落与这条小窗讨论自身的历史仍可能发送。已排队的问题使用它提交时选定的范围，之后改选不会改变队列中已有的问题。

历史消息合计约 14,000 字符预算，当前回答约 18,000 字符预算；过长材料会截取并标记。附件、图片视觉内容、未加载旧消息不在其中。后台网页本身还保留先前提问，因此缩小范围不是“重置模型记忆”。局部解释可先用默认范围，依赖此前讨论时再增加。

## 窗口与键盘

| 操作 | 效果 |
| --- | --- |
| Enter | 发送；输入法选字确认期间不发送 |
| Shift + Enter | 换行 |
| 拖动小窗顶部空白栏 | 移动小窗 |
| 拖动小窗右下角 | 调整窗口大小 |
| 左上角明暗按钮 | 切换小窗深浅色，不改变 DeepSeek 页面主题 |
| 右上角收起按钮 | 隐藏小窗，保留桌宠 |

小窗回答以文字显示，可选中复制。当前没有导出按钮或永久收藏功能；刷新前请自行复制需要的内容。

## 桌宠菜单

拖动桌宠可改变位置。右键打开菜单：

- **形象大小**：小 96px、中 144px、大 192px。默认中号，记住手动选择的尺寸。
- **动作**：仅动画角色显示，分类展开后点播。待机默认循环，提问时切换思考。点播一次后恢复当前自动状态，“恢复自动状态”可提前结束。
- **退出**：同时隐藏桌宠与小窗。再次框选文字并点击“追问”后一起恢复；扩展图标也可恢复。

“动作”首项是“随机自动播放”，默认关闭，可选每 1／3／5／10 分钟一次，刷新后记住选择。每次随机播放一个动作，结束后恢复待机。回答中、手动动作播放中、页面隐藏、桌宠退出时跳过当次触发，不补播。修改间隔会重新计时；浏览器节流可能使实际触发延后。

100 段视频来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，经 [pet-with-you](https://github.com/Refining-colors/pet-with-you) 获取。所有动作原地播放，不自主跑动，不运行工具，也不单独向模型提问。素材许可见 [NOTICE.md](../NOTICE.md)。

## 回答标签页

保留扩展创建的回答标签页，不要在它里面同时写其他问题。扩展识别到其中已有草稿时会停止提交，避免覆盖。

打开小窗时可提前加载回答页。仅该页首次提问时自动切过去，确认网页请求发出后立即返回阅读页，不等回答完成；未识别到请求但已有正文时，以正文作为返回依据。后续提问复用同一标签且不再切页。关闭回答页后，下次新建时会再初始化一次。如果已手动切到其他标签，扩展不强制返回。首次发送失败也会尝试返回，错误在小窗中显示。

状态区区分输入框加载、尝试发送与请求已发出。网页登录、验证码、网络或生成失败需在回答页处理；小窗无法代替这些步骤。“退出”只隐藏桌宠与小窗，不关闭回答页，也不取消已提交的问题。

刷新阅读页会丢失页面内的小窗历史、草稿和位置；站点的真实回答会话仍可能存在。主题、上下文、形象尺寸和随机动作间隔会保留。数据细节见 [隐私说明](../PRIVACY.md)。
